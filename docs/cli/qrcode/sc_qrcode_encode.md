## sc qrcode encode

Encode a string or file to a QR code

```
sc qrcode encode [flags]
```

### Options

```
  -e, --encode string        Encode string
  -f, --encode-file string   Encode the content of the given file
  -h, --help                 help for encode
  -o, --output-file string   Write the QR code to the given file
```
