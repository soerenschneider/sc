## sc qrcode decode

Decodes an image containing QR code to text

```
sc qrcode decode [flags]
```

### Options

```
  -f, --file string    Decodes the QR code of the given file
  -h, --help           help for decode
  -p, --print-banner   Print pre- and postfix banners (default true)
```
