## sc vault aws status

Show when AWS credentials generated by Vault expire

### Synopsis

Show information about AWS credentials that have been generated using 'generate-credentials',
such as the access key id, the Vault lease id and when the credentials expire.

The information is read from the AWS credentials file (~/.aws/credentials), Vault is not contacted.
If no profile is given, all profiles holding credentials generated by Vault are shown.

```
sc vault aws status [flags]
```

### Options

```
  -p, --aws-profile string   Only show the given AWS credentials profile section
  -h, --help                 help for status
```
